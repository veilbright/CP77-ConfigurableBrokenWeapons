# Configurable Broken Weapons
#### A mod for Cyberpunk 2077
This mod adds a simple menu to modify the rate that broken weapons are dropped by NPCs in Cyberpunk 2077.
### Requirements
- CET
- Native Settings
- Built for Patch 2.13, but should work on later versions if the core mods are updated
### Usage
Provides presets to disable broken weapons, break every dropped weapon, and reset the values to their default. The specific values that can be further edited are:
- Broken Chance, which modifies the chance for weapons to be broken
- Broken Weapon Model Chance, which modifies the increased chance for weapons NPCs drop as models outside their bodies to break
